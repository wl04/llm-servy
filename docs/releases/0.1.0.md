# LLM Servy 0.1.0

First public release of the Windows tray launcher for llama.cpp and DeepSeek Harness in WSL.

- Start and stop services, select models from INI presets, and open DeepSeek Harness.
- Connect to existing servers without taking ownership of their processes.
- Configure model and application folders independently.
- Russian and English interface, service logs, and tray controls.

## Download and run

Download `llm-servy-0.1.0-win-x64.zip`, extract the entire archive, and run `llm-servy.exe`. The optional `.zip.sha256` file contains its SHA-256 checksum.

Requires Windows x64 and [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0), installed separately. Also configure a Windows [llama.cpp build](https://github.com/ggml-org/llama.cpp/releases), compatible models/INI files, and [WSL](https://learn.microsoft.com/en-us/windows/wsl/install) with Bash, Python 3 and Node.js/npm for DeepSeek Harness. See the included README for setup and Windows/WSL networking.

## Limitations

- Initial release; configuration and features may evolve before 1.0.
- No installer or automatic updater. Exit from the tray and extract a newer release into a separate folder to update; settings remain in `%LOCALAPPDATA%\llm-servy`.
- Harness provider configuration is managed in DeepSeek Harness separately.
- Models, llama.cpp, DSH and .NET are not bundled.
