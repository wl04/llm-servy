# LLM Servy 0.2.2

- Open Pi starts a new Pi process after normal exit or failure, preserving the running llama.cpp server and loaded model.
- Terminal clients detach successfully before the private tmux server shuts down. Pi exit codes remain separate from terminal-client exit codes.
- Reopening uses the active session settings and is serialized with Stop; failures leave llama.cpp running and allow retry.

Closing the terminal still leaves Pi running. Exiting Pi does not automatically restart it. A new process does not automatically resume the previous conversation. Windows Terminal controls whether a successfully exited tab closes.
