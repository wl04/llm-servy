# LLM Servy 0.2.0

- Added Pi CLI support in WSL through isolated tmux sessions.
- Added harness selection and separate working folders for DeepSeek Harness and Pi.
- Open Pi attaches Windows Terminal to the same running process, including after closing the terminal.
- Pi process lifecycle is shown in the main window; Stop and Exit clean up the managed session.
- Existing DeepSeek Harness settings remain compatible. New Pi settings and messages support English and Russian.

Pi requires an existing installation in WSL, tmux, Windows Terminal, and a configured Pi model provider. Agent activity and recovery across application/WSL restarts are outside this release's scope.

Download the Windows x64 ZIP, extract the entire archive and run `llm-servy.exe`. .NET Desktop Runtime 10 x64 is required and is not bundled.
