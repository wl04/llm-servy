# LLM Servy 0.2.3

- Fixed a race during Pi shutdown: the supervisor now waits for terminal clients to finish detaching before stopping its private tmux server.
- Preserved Pi's exit code when client detachment is delayed, instead of incorrectly reporting a cleanup failure with exit code 1.
- Added regression tests for delayed detachment, timeout, and client-query failures.

Download the Windows x64 ZIP and extract the entire archive. .NET Desktop Runtime 10 x64 is required and is not bundled. Exit LLM Servy from the tray before updating, then launch the new version. Existing settings are reused automatically.
