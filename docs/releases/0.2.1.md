# LLM Servy 0.2.1

- Enabled tmux extended key reporting for Pi, removing the warning about modified Enter keys.
- Selected CSI-u reporting on tmux 3.5 and newer; tmux 3.2–3.4 keeps its supported xterm format.

The settings apply to LLM Servy's private tmux server. No changes to `~/.tmux.conf` are needed. Stop Pi and exit LLM Servy before updating, then start a new session. Actual key combinations also depend on Windows Terminal key bindings and capabilities.
