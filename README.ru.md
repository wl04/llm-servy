# LLM Servy

[English](README.md) · Русский

Windows-приложение с управлением из трея для запуска **llama.cpp в Windows** и **DeepSeek Harness в WSL**. Запускайте и останавливайте сервисы, выбирайте модели из INI и открывайте веб-интерфейс harness из одного окна.

## Возможности

- Выбор моделей из INI в указанной папке.
- Фоновый запуск сервисов с журналом в окне приложения.
- Подключение к работающим серверам; приложение останавливает только запущенные им процессы.
- Управление из трея и интерфейс на русском или английском.

## Требования

- Windows x64 и .NET Desktop Runtime 10 x64.
- Windows-версия llama.cpp с поддержкой `--models-preset`, `/v1/models` и `/props?autoload=true&model=…`.
- Модели и INI-пресеты, совместимые с установленной версией llama.cpp и вашим оборудованием.
- Дистрибутив WSL с Bash, Python 3 и Node.js с npm/npx, совместимыми с выбранной версией DeepSeek Harness.

DeepSeek Harness должен быть доступен в WSL. Если указанная версия пакета не установлена и отсутствует в кеше, LLM Servy устанавливает её через npx; для этого нужен доступ к сети. Оболочка входа WSL должна находить Node.js и Python.

## Быстрый запуск

1. [Соберите приложение](#сборка-из-исходников) и откройте `artifacts\publish\llm-servy.exe`. Сохраняйте всю папку сборки целиком, включая `ru` и `wsl`.
2. В **Настройках** выберите папку моделей и INI, папку llama.cpp, дистрибутив WSL и существующую рабочую папку harness в WSL. Укажите точную версию пакета DeepSeek Harness.
3. Настройте провайдер DeepSeek Harness: укажите адрес API llama.cpp, доступный из WSL, и идентификатор модели из секции INI. LLM Servy не редактирует настройки провайдера harness.
4. Выберите модель, нажмите **Запустить**, затем **Открыть DeepSeek Harness**, когда кнопка станет доступна. Выберите соответствующую модель в harness.

Порты по умолчанию: **1234** для llama.cpp и **3080** для веб-интерфейса harness. Сервисы запускаются кнопкой **Запустить**. Крестик скрывает окно в трей; **Выход** останавливает запущенные приложением сервисы и закрывает его.

## Настройки

- Читаются только INI непосредственно в выбранной папке моделей. Пути к моделям внутри INI отсчитываются от папки этого INI.
- Приложение, INI и файлы моделей могут находиться в разных местах. Рабочая папка harness задаётся отдельно.
- Пустое поле папки llama.cpp включает автоматический поиск исполняемого файла. В явно указанной папке ищется `llama-server.exe`, затем `llama.exe`.
- Изменения параметров сервисов применяются при следующем запуске. **Настройки → Интерфейс → Язык** меняет язык после сохранения без перезапуска сервисов. Системный режим выбирает русский для русской Windows и английский в остальных случаях.

Настройки: `%LOCALAPPDATA%\llm-servy\settings.json`. Журнал: `%LOCALAPPDATA%\llm-servy\logs\launcher.log`. Оба файла открываются из **Настроек**. Токены входа в harness хранятся в памяти и скрываются в журнале; вывод сервисов сохраняется на исходном языке.

## Сборка из исходников

Используйте терминал Windows в корне репозитория. Версия SDK указана в [global.json](global.json).

```powershell
dotnet build llm-servy.slnx
.\publish.ps1
```

Приложение написано на C# с WinForms на .NET 10. Отладка, тесты, архитектура, локализация и импорт настроек описаны в [руководстве разработчика](docs/development.md) на английском.
